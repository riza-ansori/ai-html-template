# AI HTML Template

A modern SaaS HTML template built with HTML, CSS, JavaScript, Vite, and Tailwind CSS.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Vite
- Tailwind CSS
- npm

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server
```bash
npm run dev
```

Build for production
```bash
npm run build
```

Preview production build
```bash
npm run build
```
